637a03修華嚴奧旨妄盡還源觀637a05唐大薦福寺翻經沙門法藏述

白話試譯

題目的意思是：修習《華嚴經》幽奧的宗旨，令虛妄滅盡、回歸自性本源的觀法。「妄盡」即妄想分別執著淨盡，「還源」即返還自性清淨圓明之體。署款表明本篇為唐代長安大薦福寺從事譯經的沙門法藏（賢首國師）所撰述。

題目的意思是：修習《華嚴經》幽奧的宗旨，令虛妄滅盡、回歸自性本源的觀法。「妄盡」即妄想分別執著淨盡，「還源」即返還自性清淨圓明之體。署款表明本篇為唐代長安大薦福寺從事譯經的沙門法藏（賢首國師）所撰述。

白話為本站試譯（未經法師審定），僅供學習參考。

出處：體佛法師《修華嚴奧旨妄盡還源觀》講義 第 1 集

第一集開講，法師先說明為何講此觀：《華嚴》八十萬字浩瀚無涯，罕有人能講全，而賢首國師把全經要旨總攝為《妄盡還源觀》，「分成六門而入」——一體、二用、三遍、四德、五止、六觀，把宇宙的因果性相說得清楚；了解此觀，「整個華嚴的富貴全部在你心中」。題下署款之「法藏」即賢首國師，法師遂從唐代八宗講起，次述華嚴初祖杜順、二祖智儼、三祖法藏的傳承故事，歸結於「性相一如」：以金作器，器器皆金。

  1. 唐代八宗如八個手指，方向不同、同指一月，目的都是明心見性；其中華嚴宗經義最完整，性相、理事全部圓融。體佛 第1集
  2. 此觀不是經，而是祖師依《華嚴》所作的論述；賢首國師以六門總攝八十萬言，故從此觀可窺全經。體佛 第1集
  3. 初祖杜順（法順）以法界觀教化，遣弟子智沖持書往五台：青樓女子、農家之豬讀信坐化，偈云「游子漫波波，台山禮土坡，文殊只這是，何必問彌陀」——相雖不同，性本是佛，文殊不在心外。體佛 第1集
  4. 法藏為武則天以金獅子作喻：只見金是落空，只見獅子是著相，「既是黃金也是獅子」方是性相一如，即《心經》色不異空、空不異色之義。體佛 第1集
  5. 華嚴宗所以又稱賢首宗：武則天以法藏為賢首菩薩化身，尊為賢首國師；法藏承杜順、智儼之學，具體化而成《妄盡還源觀》。體佛 第1集

整理說明：本集前半以宗派史與祖師傳說為主。其中「金獅子章」實為法藏另撰之《華嚴金師子章》，非《華嚴經》品名；杜順生卒、八宗次第等史傳細節，講者自言「不是重點」，讀者宜另參僧傳。本摘要據體佛法師講義整理。

講記為本站學習摘要，非講者原文；完整內容請參原講。

出處：12-046 第 1、2 集

法師於開講緣起中指出：《華嚴經》卷帙浩繁、境界深廣無際，自古學人皆望契入而苦無下手處。華嚴宗歷代祖師——杜順、雲華（智儼）、賢首（法藏）、清涼（澄觀）、宗密——代代承傳，將深廣無際的教義拈出修行切要的精髓，即此《修華嚴奧旨妄盡還源觀》；本篇題下署「賢首國師著」。法師曾於講席中簡介末後五止六觀，因同學請求依全文學習，遂於 2008 年起先後兩次宣講（檔名 12-046 三十六集、12-047 一百零八集）。

  1. 《華嚴》如大經所說卷數太多、境界深廣無際，自古以來人人想入華嚴境界而難得其門；祖師慈悲，說出「妄盡還源」這一觀門，把複雜深廣的教義拈出修行切要的精髓，非常難得。12-046-001
  2. 此觀經雲華、賢首、清涼、宗密代代承傳；法師依題下署款稱本篇為賢首國師之作，開講即依全文逐段學習。12-046-001
  3. 清涼大師《疏鈔》說華嚴當機有十類，最後一類是「大心凡夫」——雖妄想分別執著未斷，但心量廣大、「心包太虛，量周沙界」，也能承當《華嚴》，這給末世學人極大的鼓勵。12-046-002

整理說明：「題目與署款」一段無逐句講解命中；本條僅據 12-046 第一、二集開篇之緣起與傳承開示整理。關於本篇作者，宋淨源後序考定為賢首法藏所著（見 8.0），法師開示中亦兼提杜順和尚拈出此觀之傳說，並存之。
